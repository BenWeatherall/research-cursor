## Project Summary

Research Cursor is a **Cursor configuration–only** repository: agents, commands, rules, skills, and workflows. It has **no application code**, so agents are not biased by existing codebases. It is used to validate Cursor pipelines and to produce **reports** (e.g. tool or library research) under `reports/{report-name}/` and archive summaries under `_archive/`.

- **Main components:** `.cursor/` (agents, commands, rules, skills, workflows), `docs/` (workflow docs and AI context), `reports/`, `_archive/`, `_features/`, `_bugs/`

---

## Environment & Versions

- **No application runtime.** No `install.sh`, `pyproject.toml`, or virtual environment. Clone and use Cursor Composer.
- **Path conventions** (defaults): `.cursor/CONVENTIONS.md`. Overrides: project README or `.cursor/rules`.

## Key Commands (Shell)

| Purpose | Command / Action |
|--------|--------------------|
| Setup | None; clone only. No dependencies. |
| Run pipeline | In Cursor Composer: `/feature-pipeline`, `/bug-pipeline`, `/update_context` |
| Lint / tests | Not applicable (no application code). |

---

## Runtime Entry Points

- **No runnable application.** Entry points are **Cursor Composer commands**:
  - `/feature-pipeline` — research → plan → implement → archive (use with feature file in `_features/`)
  - `/bug-pipeline` — bug investigation and fixes (`_bugs/`)
  - `/update_context` — (re)generate AI context in `docs/AI_CONTEXT/`

---

## Core Interfaces (Quick View)

- **Pipeline input:** Feature file in `_features/{name}.md` with **Background**, **This Task**, **Testing Needed**.
- **Pipeline output:** Report in `reports/{name}/`; summary in `_archive/{name}/`.
- **Context output:** Quick reference, repository, patterns, and per-component docs in `docs/AI_CONTEXT/`.

## Quick Troubleshooting Hints

| Issue | Check / Action |
|-------|----------------|
| Path confusion | Resolve placeholders from `.cursor/CONVENTIONS.md`; overrides in README or `.cursor/rules`. |
| Where do reports go? | `reports/{report-name}/` only; not under `docs/`. |
| Where do AI context docs go? | `docs/AI_CONTEXT/`; generated by `/update_context`. |
| Pipeline not running | Use Composer; do not invoke workflow files directly. |
